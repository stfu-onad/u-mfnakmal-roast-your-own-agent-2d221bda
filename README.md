# Roast Your Own Agent

Entry for the make.fun bounty
[u-mfnakmal-roast-your-own-agent-2d221bda](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)

`main.py` (Python 3.13, standard library only) writes a single-line roast of
the entrant's own AI agent to `/output/entry.txt` — funny, playful, never
hateful, under 200 characters.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
